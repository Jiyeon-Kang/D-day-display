# D-day-display

Flutter로 만든 입자 트리 애니메이션입니다. Android, iOS, 웹을 지원합니다.

- 처음 실행하면 입자 2,200개가 세 그루의 트리로 모입니다. 기본색은 가운데 민트색(`#99EEDD`), 양쪽 분홍색(`#FFAACC`)입니다.
- iPhone 15 화면에 맞춘 큰 정면 구도로 세 트리가 각자의 자리에서 회전하고, 눈송이 160개가 이어집니다.
- 완성된 트리는 다시 보기를 누르기 전까지 흩어지지 않고 계속 유지됩니다.
- **다시 보기**: 현재 장면과 입자 글자가 함께 다시 모입니다. 일시정지 중에도 바로 재생합니다.
- **일시정지 / 재생**: 눈과 현재 장면의 움직임을 함께 멈추거나 이어 재생합니다.
- 앱이 백그라운드로 이동하면 멈추고, 돌아오면 같은 지점에서 이어집니다.
- 매년 12월 1일부터 25일까지 단말의 현지 날짜 기준 크리스마스 D-day가 화면 위에 표시됩니다.
  12월 1일은 `D-24`, 24일은 `D-1`, 25일은 `merry christmas!`로 표시합니다.
- D-day와 인사말도 트리처럼 작은 민트색·분홍색 입자가 모여 글자를 만들고 반짝입니다.
  일반 텍스트 헤더나 카드는 표시하지 않습니다.
- 12월 1일부터 25일까지 날짜가 지날 때마다 트리 세 그루의 오너먼트가 하루에 1~2개씩 늘어납니다.
  전체 개수는 1일 1개, 2일 3개, 3일 4개처럼 늘어나 25일에는 37개가 됩니다.
  여러 색의 작은 점으로 만든 장식 종류도 단계별로 늘어납니다. 1일에는 쿠키만,
  7일부터 지팡이 사탕, 12일부터 눈사람, 17일부터 산타, 22일부터 루돌프가 추가됩니다.
  새 종류가 열려도 이미 달린 장식은 그대로 남고, 새 장식에 기존 종류와 새 종류가 섞입니다.
  먼저 생긴 장식의 모양과 자리는 유지되며, 25일에는 중앙 트리 꼭대기에 금색 점 별이 나타납니다.
- 12월 7일부터 25일까지는 초록 트리에 빨간 입자 리본과 다양한 크리스마스 오너먼트가 어우러집니다.
  1~4일은 기존 민트·분홍 트리, 5·6일은 아래 생일 화면을 표시합니다.
- 매년 12월 5일과 6일에는 트리 대신 생일 캐릭터 두 명이 함께 모이고,
  위에는 `雫、誕生日おめでとう〜`가 입자로 표시됩니다. 머리의 기본색은 왼쪽 민트색
  `#99EEDD`, 오른쪽 분홍색 `#FFAACC`를 유지하고, 원본의 HAPPY BIRTHDAY 글자는 제거했습니다.
  얼굴과 손은 로즈 라벤더(`#E8D8EE`), 옷은 연보라, 케이크는 피스타치오색, 접시는 차분한 파랑,
  장식은 연한 금색으로 나눠 경계가 보이도록 합니다.
- 생일 화면 뒤에는 작은 점 하트 몇 개가 은은하게 반짝입니다. 하트도 한 번 모인 뒤
  유지되며, 캐릭터와 함께 일시정지하거나 다시 보기로 처음부터 재생됩니다.
- 날짜는 자정과 앱 복귀 시 갱신되며, 수동 시각·시간대 변경도 30초 이내에 확인합니다.
  트리를 일시정지해도 날짜는 계속 갱신됩니다.

## 실행

Flutter 3.22.2 / Dart 3.4.3 이상이 필요합니다.

```bash
flutter pub get
flutter run
```

연결된 기기나 실행 중인 시뮬레이터를 선택하면 됩니다.

실행 중 코드를 수정했다면 `flutter run` 터미널에서 `r`로 반영하거나,
`R`로 앱 상태를 초기화해 다시 시작할 수 있습니다. 설치 파일로 실행 중이라면
최신 소스로 다시 빌드하고 설치해야 변경 내용이 반영됩니다.

웹으로 실행하려면:

```bash
flutter run -d chrome
```

iOS 실행에는 Xcode, Android 실행에는 Android SDK가 필요합니다.

### 날짜 미리보기

디버그 실행에서는 화면 아래 `<`, `>`로 이전·다음 현지 날짜를 확인할 수 있습니다.
선택한 날짜에는 `테스트` 표시가 붙고, 달력 버튼을 누르면 실제 단말 날짜로 돌아갑니다.
날짜를 직접 바꾸면 장면과 글자가 처음부터 재생되며, 단말의 시각은 변경하지 않습니다.
오너먼트 개수, 7일부터의 트리 색, 25일의 꼭대기 별도 선택한 날짜를 따릅니다.

시작 날짜를 지정할 수도 있습니다.

```bash
flutter run --dart-define=CHRISTMAS_PREVIEW_DATE=2026-12-10
```

이 예시는 12월 10일 기준 입자 글자 `D-15`를 표시합니다. 생일 장면은 다음 명령으로 확인합니다.

```bash
flutter run --dart-define=CHRISTMAS_PREVIEW_DATE=2026-12-05
```

옵션 없이 실행하면 단말 날짜를 따릅니다. 날짜 테스트 버튼과 미리보기 옵션은
디버그 전용이며, 릴리스 빌드는 항상 실제 단말 날짜를 사용합니다.

## 코드

- `lib/main.dart`: 앱 시작, 테마, 세로 화면 설정
- `lib/particle_tree.dart`: 화면, 재생 버튼, 앱 생명주기 처리
- `lib/particle_forest.dart`: 입자 생성과 Canvas 렌더링
- `lib/tree_season.dart`: 현지 날짜별 오너먼트 개수, 트리 색, 꼭대기 별 표시
- `lib/christmas_ornament.dart`: 쿠키·사탕·눈사람·산타·루돌프의 점 모양과 색상
- `lib/scene_date_controller.dart`: 현지 날짜 갱신과 디버그 날짜 이동
- `lib/birthday_scene.dart`, `lib/particle_character.dart`: 생일 이미지의 입자 변환과 렌더링
- `lib/birthday_hearts.dart`: 생일 화면 배경의 점 하트
- `lib/birthday_glyphs.dart`: 생일 인사말의 점 글자 데이터

애니메이션은 Flutter SDK의 Canvas로 그리며 추가 런타임 패키지나 서버 연결은 필요하지 않습니다.
`assets/birthday_characters.png`는 사용자가 제공한 스티커를 내장 `image_gen`으로 편집한 이미지이며,
편집 지시는 `assets/birthday_characters.prompt.txt`에 기록했습니다. 이미지의 윤곽과 주변 색을
추출해 민트색·분홍색을 기본으로 세부 색을 나눈 입자로 그립니다. 입자 색과 하트는
코드에서 처리하므로 원본 이미지를 다시 편집하지 않습니다. 일본어 글자는 Noto Sans JP에서 추출한 점 데이터로 내장하며,
라이선스는 `assets/licenses/NotoSansJP-OFL.txt`에 있습니다. 실행 중 폰트를 불러오지 않습니다.
프레임마다 화면 전체를 빌드하지 않도록
[CustomPainter의 repaint](https://api.flutter.dev/flutter/rendering/CustomPainter-class.html)를
사용합니다.
